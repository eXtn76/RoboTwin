# RoboTwin-Protokoll

> Platzhalter – wird in Meilenstein M5 ausgearbeitet.

## Geplante Gliederung

1. Transport (TCP, Port, Zeichenkodierung, eine JSON-Nachricht pro Zeile)
2. Nachrichten Client → Controller (`move_joints`, `move_linear`, `stop`, …)
3. Nachrichten Controller → Client (`ack`, `error`, `state`)
4. Ablauf und Zustände (Verbinden, Befehl, Bestätigung, Zustandsmeldungen)
5. Fehlercodes
6. Beispiele
